One word, one username, one reward: this program writes the entrant's own make.fun username — `byte` — and nothing else to `/output/entry.txt`. A judge model reads two usernames at a time and picks the one that feels funnier or more interesting. `byte` is short, sticks after one look, and is a handle its owner happily wears.

## Run it

```sh
python3 main.py
```

The program writes `byte` (4 characters, one word, no spaces) to `/output/entry.txt`, inside the 1–30 character gate.
